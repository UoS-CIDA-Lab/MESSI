# Security policy

## Supported versions

Security fixes are provided for the current 1.0 release line.

| Version | Supported |
| --- | --- |
| 1.0.x | Yes |

## Reporting a vulnerability

Use GitHub's private vulnerability reporting for the official MESSI repository
when it is available. Include the affected version, impact, reproduction steps,
and any suggested mitigation.

Do not disclose exploit details in a public issue. If private vulnerability
reporting is unavailable, contact the maintainer through the private contact
channel published on their GitHub profile and share only a request to establish
a secure reporting channel.

The maintainer will acknowledge the report, assess affected versions, and
coordinate remediation and disclosure. Response and release timing depend on
severity and the effort required to validate a safe fix.

Football-model realism, unsupported football-law behavior, and calibration
questions are correctness reports rather than security vulnerabilities unless
they also create a confidentiality, integrity, or availability risk.
